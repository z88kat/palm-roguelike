  <p><b>24 November 2026</b> - The roguelikes are back!  iRogue, iLarn and
   kMoria have been revived.  The source code, with its full CVS history,
   now lives on <a href="https://github.com/z88kat/palm-roguelike">GitHub</a>,
   the games build again with a modern toolchain, and this website has been
   restored.  All three got the same treatment: a code review with plenty of
   bug fixes, updated About, License and History screens, a player's manual
   (also as a Palm DOC e-book to read on the device), a bright new colour
   scheme that works on both the white and the Invert (black) background, and
   support for the 5-way navigator on Palm OS 5 devices such as the
   Tungsten C.</p>
  <p><b><a href="iRogue/index.php">iRogue</a> 1.2</b> - Colour is built in
   now (an iRogue-RGB memo only overrides the symbols it lists), the 5-way
   walks and runs, and Edit Colors covers every monster.  Fixes for crashes,
   memory errors, save and restore bugs, and several rules mistakes.
   <a href="https://github.com/z88kat/palm-roguelike/blob/main/iRogue/MANUAL.md">Manual</a></p>
  <p><b><a href="iLarn/index.php">iLarn</a> 0.40</b> - Built-in colours for
   every item, building and monster, and the whole game can now be played
   with the 5-way and no stylus: character design, stores, the bank,
   inventory, spells, menus and the map.  Fixes for hangs, crashes, save
   problems, memory leaks and rules bugs.
   <a href="https://github.com/z88kat/palm-roguelike/blob/main/iLarn/MANUAL.md">Manual</a></p>
  <p><b><a href="kMoria/index.php">kMoria</a> 0.16</b> - A new colour scheme
   (kMoriaColorDB.pdb), walking into a closed door opens it, stores list
   their stock in an Item | Gold table, the 5-way walks, and "." (rest) has
   a menu item and takes a count, e.g. "20." rests for 20 turns.
   <a href="https://github.com/z88kat/palm-roguelike/blob/main/kMoria/MANUAL.md">Manual</a></p>
  <p>There are no prebuilt downloads of the new versions yet; build them from
   the GitHub source for now.  Each game's download page still offers the
   original releases.</p>
