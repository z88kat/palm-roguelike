iRogue status

What's new in the current version?

The current version of iRogue is 1.2 (November 2026), the first new version since 2002. Its source is on GitHub, together with the player's manual and the full list of changes. Download iRogue 1.2 here.

(From 1.0.0 to 1.1.1 iRogue used major.minor.patchlevel numbering, with even minor versions stable and odd ones for development: 1.1.1 was the last development version and 1.0.0 the last stable one.)

What's new in 1.2

  • Colour out of the box. A built-in "neon" colour scheme gives every kind of item and every monster its own colour, readable on both the white and the Invert (black) background. It is on by default on a colour screen. An iRogue-RGB memo (see Color) still works, and now only overrides the symbols it lists.
  • A tile set at last. Ticking Tiles in Preferences now draws the map with colour pictures: walls, floors, doors, stairs, traps, every kind of item, you, and all 52 monsters. Install iRogueTileDB.prc alongside the game (Palm OS 3.5 or later). Version 1.1.1 only came with a starter set of plain letters.
  • 5-way navigator on Palm OS 5 devices such as the Tungsten C: up, down, left and right walk, holding keeps walking, and with caps lock on you run. The centre button takes the stairs when you are on them and searches otherwise. The navigator also aims in the direction picker and closes the map. The Up/Down buttons of older Palms still take the stairs.
  • Edit Colors covers every monster (some were missing), and saving replaces the iRogue-RGB memo instead of adding another copy.
  • New About, License and History screens, rewritten Instructions, and a player's manual that also comes as a Palm DOC e-book (iRogue-manual.pdb).
  • Bug fixes
    - crashes: inventory "call" could open the naming form on a weapon; the Restore list crashed when there were no saves yet.
    - memory errors, e.g. a thief stealing while you were frozen by an ice monster, and reading a scroll of sleep.
    - saves: restoring a game kept the previous game's armour, weapon and rings (a phantom armour class) and some of its monsters.
    - memory leaks in the throw/zap list, the save list and "Play Again".
    - throwing or zapping item 27 or later used the wrong item.
    - dying while asleep stopped you ever falling asleep again in that session.
    - reading identify as your last item left you stuck in an empty list.
    - rules, as in Rogue Clone: rings of burden and adornment had swapped names, a ring of aggravate monster did nothing, 2-3 rings used more food than 4-8, and the three rooms every level needs were always the top row.

What's new in 1.1.1

Support for graphical tiles (currently restricted to OS 3.5 and higher)
This has been requested several times. iRogue can now use 9x10 icons (same as DateBk5 or Action Names) in place of ASCII characters. However, since my artistic ability is negligible, it is up to y'all to create a nice-looking set of tiles (consult the README file in this release for further instructions).

What's new in 1.1.0

These are new features that were not in 1.0.0:

  • Added some HandEra 330 support
    + can minimize the virtual silk screen for 33% more dungeon height
    + use the much nicer OS-provided font for 'small font'
    + those wacky new icon sizes
    + probably some other thing that I forget
    - screen rotation is not supported in this release
  • Minor bug fixes (these will be plowed into bugfix release 1.0.1 in the "stable" branch)
    - make 'zap' check to see whether you have any wands.
    - make messages not clear when hardware button pressed in popup forms. heh. (maybe you noticed this if you, e.g., scrolled the text in the top-ten list using the hardware up/down buttons.)
    - increment FontID, maybe this will fix problem reported for Kyocera. Or, maybe not. Who knows.

What was new in 1.0.0

(1.0.0 is just 0.47, relabelled. These are the changes since the 0.42 release.)

  • Color defined by the user.
  • You can get black background (even if you do not have color) by checking the "Invert" box in Preferences.
  • New preference to automatically sort your inventory.
  • New preference to show pie slices on the screen (may still be buggy).
  • Top score list can be viewed any time via the menu.
  • Menus and the Preferences screen are reorganized just to confuse you.
  • Fixed some bugs
    The screen scrolls sooner, before you run out of 'walk' donut in east/west.
    Fixed the "hardware scroll-buttons in object creation form" bug.
  • Created some bugs
    When the screen is black-background, the Graffiti shift indicator leaves white behind itself (e.g. if you tap for punctuation).

Bugs

Please report any bugs you find on GitHub and they will be fixed as time permits.

iRogue comes with absolutely no warranty. The worst case for a buggy application is a hard reset which means losing everything since your last backup. Caveat emptor.
