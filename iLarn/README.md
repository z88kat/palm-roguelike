# iLarn

Larn for Palm OS, by Bridget Spitznagel (2000–2001). This directory is a
checkout of the original CVS repository, which is kept with full history in
[`../cvs-repo/iLarn`](../cvs-repo/iLarn).

## Which version this is

iLarn has no branches, so this is the trunk head: the `Release-2001_08_06`
release plus a few small changes from that time that were only committed in
March 2004 (`main.c`, `iLarn.rcp`). That called itself 0.30.

On top of the trunk head come the v0.40 changes described in
[Changes in v0.40](#changes-in-v040).

## Layout

| Path | What it is |
| --- | --- |
| `src/` | The game (C sources, `iLarn.rcp` resources, `Makefile`) |
| `src/iLarnDB.pdb` | Game-data database (source copy; `make` copies it to `build/`) |
| `src/FixDB/` | Palm utility that originally built/repaired `iLarnDB.pdb` |
| `src/Icon/round/` | Alternative app icon |
| `MANUAL.md` | The player's manual |
| `build/` | Created by `make`: everything to install (see below) |

## Building

Same toolchain as [kMoria](../kMoria/README.md):

```sh
./tools/build-pilrc.sh     # one-time, from the repo root
cd iLarn/src && make       # -> ../build/
make install               # everything in build/ via pilot-xfer over USB
```

`make` puts everything to install in `iLarn/build/`:

| File | What it is |
| --- | --- |
| `iLarn.prc` | The game |
| `iLarnDB.pdb` | Game data (stores, monsters, text) — **must be installed with the app** |
| `iLarn-manual.pdb` | Optional Palm DOC e-book of `MANUAL.md`, generated by `../tools/make-ilarn-manual.py` |

Intermediate files (`.o`, `.bin`, ...) stay in `src/`. `make veryclean`
removes them and `build/`.

Build changes for a modern Mac: toolchain paths, `m68k-palmos-multigen`,
and the patched pilrc. iLarn doesn't use the HandEra headers, so it needs
no `compat/` shim. The Makefile listed `sphere.c` instead of `sphere.o`,
and resources weren't rebuilt when `iLarnRsc.h` changed; both are fixed.

## Changes in v0.40

- **Neon colours.** A built-in colour scheme, the same palette as iRogue's
  and kMoria's: every kind of item, every town building and every monster
  (dragons and demons included) has its own vivid colour; walls and `@`
  stay plain. It is on by default for a new install on a colour screen.
  The `iLarn-RGB` memo still works and now only overrides the symbols it
  lists.
- **5-way navigator** (Tungsten C and other Palm OS 5 devices): up / down /
  left / right walk, holding it keeps walking, and with caps lock on it
  runs. Centre rests a turn (which offers again whatever you stand on), and
  clears `--more--`. While a spell or Fight waits for a direction, the
  5-way aims it and centre cancels. The whole game can be played without
  the stylus:
  - character design: up / down class, left / right male / female, centre
    starts;
  - the popup of things to do: a frame moves between the buttons, centre
    presses it;
  - inventory, spell list, DND store, college, bank, Dealer McDope's: up /
    down pick, centre buys / uses, left leaves (the DND store turns pages
    at the ends of the list);
  - bank transaction and LRS: a frame moves between the buttons;
  - menus, message log, high scores, About, home and map all respond.
- About box, License and History updated: no more SourceForge links or old
  email address, the GPL text and credits on one screen, and the story
  since 2001. Instructions rewritten. Version bumped to 0.40.
- `MANUAL.md` and an e-book of it, `iLarn-manual.pdb`.

Bug fixes:

- **Hangs and crashes:** a sphere of annihilation near the map edge looped
  forever; a monster's flood-fill and the screen refresh could run off the
  map; alter reality didn't check its allocation; the inventory letter
  search started one past the end of the list.
- **Saves:** records were left busy when a save failed half-way and two
  record pointers were never unlocked; walls-with-monsters were packed
  differently from how they were unpacked.
- **Leaks:** the known-potion and known-scroll tables, the inventory and
  spell lists (when closed without choosing), the high-score record, and
  alter reality's copy of the level.
- **Stuck states:** tapping the screen while aiming Fight left Fight armed
  forever; unknown keys took a turn; a consumed wielded item stayed
  "wielded".
- **Rules:** the orb of dragon slaying fell through into the sword's -5
  DEX; the amulet of invisibility didn't stop see-invisible wearing off;
  the talisman of the sphere protected monsters too; a demon dispelling a
  sphere vanished; the dead throne skipped its abuse count; the altar
  enchant was applied twice; one class got protection it shouldn't have;
  dropped gold over 32,767 overflowed; a new game kept the Eye of Larn's
  and see-invisible's effects; selling the Eye of Larn at the bank left
  demons visible; gold piles merged wrongly.
- **Small things:** player names weren't always terminated; a square you
  knew only from a monster seen there showed an unrelated object's symbol
  (the monster's number looked up in the object table); the altar asked
  "Drop how much?"; a hardware button bound to Map opened it in town,
  where the menu refuses; the bank's Sell with nothing selected read a bad
  pointer.

Known and left alone: the altar takes two turns (as in Ularn); mirrors and
some pathfinding oddities are inherited from Ularn. On Palm OS 5.4+
devices the new Memos app keeps memos elsewhere, so the `iLarn-RGB` memo
is ignored there (the built-in colours still work).

## Testing in CloudpilotEmu

See [kMoria's README](../kMoria/README.md#testing-in-cloudpilotemu) for the
setup. iLarn needs its data database as well as the app:

```sh
cd ~/Development/GitHub/palm-roguelike/iLarn/build
echo "install $PWD/iLarnDB.pdb"      >> /tmp/tc-cmds.txt
echo "install $PWD/iLarn.prc"        >> /tmp/tc-cmds.txt
echo "install $PWD/iLarn-manual.pdb" >> /tmp/tc-cmds.txt
echo "launch iLarn"                  >> /tmp/tc-cmds.txt
```

In `cp-uarm` (Tungsten C) the Mac's arrow keys are the 5-way and keypad
Enter is its centre button; F6 opens the menu, which the arrows also
navigate. To replace the app while it is running, launch another app
first (e.g. `launch Preferences`), then install and relaunch.
