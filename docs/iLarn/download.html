iLarn 0.40 (November 2026)

The current version. Download these files and install them with HotSync, or drag them onto an emulator such as CloudpilotEmu:

  • iLarn.prc - the game.
  • iLarnDB.pdb - the game data: must be installed too.
  • iLarn-manual.pdb - optional: the player's manual as a Palm DOC e-book.

See what's new, or read the manual online. You might also like to read about how to play. Found a bug? Please report it on GitHub.

System requirements

OS: Palm OS 3.5 or higher. On Palm OS 5 devices with a 5-way navigator (Tungsten C and others) the whole game can be played without the stylus.
Memory: about 170 K for the game and iLarnDB, plus up to about 20 K while a game has saved some dungeon levels.

What if I delete a database?

iLarn will not run without iLarnDB.pdb (which you installed above). If you reinstall a clean copy of iLarnDB.pdb, you will wipe out your top ten list (but it will not hurt your current character). iLarn also creates a database iLarnSaveDB.pdb. If you delete iLarnSaveDB.pdb, you will lose your current character (but it will not affect your top ten list).

Original releases

The releases from 2000 and 2001 are still on SourceForge. The last was 0.25 (alpha), and the last one called stable was 0.20; see all iLarn releases. They also run on Palm OS 2: each zip has iLarn.prc for OS 3 and iLarnOS2.prc for OS 2, and iLarnDB.pdb must be installed with either.
