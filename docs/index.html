Roguelikes for PalmOS

mission: to port roguelike games to PalmOS devices.

~ News ~

24 November 2026 - The roguelikes are back! iRogue, iLarn and kMoria have been revived. The source code, with its full CVS history, now lives on GitHub, the games build again with a modern toolchain, and this website has been restored. All three got the same treatment: a code review with plenty of bug fixes, updated About, License and History screens, a player's manual (also as a Palm DOC e-book to read on the device), a bright new colour scheme that works on both the white and the Invert (black) background, and support for the 5-way navigator on Palm OS 5 devices such as the Tungsten C.

iRogue 1.2 - Colour is built in now (an iRogue-RGB memo only overrides the symbols it lists), the 5-way walks and runs, and Edit Colors covers every monster. Fixes for crashes, memory errors, save and restore bugs, and several rules mistakes. Manual

iLarn 0.40 - Built-in colours for every item, building and monster, and the whole game can now be played with the 5-way and no stylus: character design, stores, the bank, inventory, spells, menus and the map. Fixes for hangs, crashes, save problems, memory leaks and rules bugs. Manual

kMoria 0.16 - A new colour scheme (kMoriaColorDB.pdb), walking into a closed door opens it, stores list their stock in an Item | Gold table, the 5-way walks, and "." (rest) has a menu item and takes a count, e.g. "20." rests for 20 turns. Manual

There are no prebuilt downloads of the new versions yet; build them from the GitHub source for now. Each game's download page still offers the original releases.

August, 2006 - I've converted the website from tables to CSS for a cleaner look, and fixed any dead external links. (Games maintenance? Maybe when the kids are sleeping through the night, for which I'm not holding my breath.)

1 Nov 2003 - Released a new version of PaleoHack (hosted at berlios.de) and caught up on email.

11 May 2002 - Released experimental branch iRogue 1.1.1 with support for graphical tiles; requires OS 3.5 or later. Tilesets can be created with the dbIcon+ utility (freeware) available from Pimlico Software.

29 March 2002 - Released kMoria 0.15. Mostly bug fixes, a few requested features.
