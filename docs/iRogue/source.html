iRogue source code

Where's the source?

On GitHub, in the iRogue folder of the palm-roguelike repository. The original CVS repository is there too, with its full history (cvs-repo/iRogue). iRogue 1.2 is built from the head of the HandEra branch, where all development after April 2001 happened.

What do I need to compile it?

Today the games build on macOS with the palmdev-macos toolchain (prc-tools with m68k-palmos-gcc 2.95) and the Palm OS SDKs. The README explains how, and how to test the game in the CloudpilotEmu emulator.

The original build notes (2002)

(Kept for history: the prc-tools and emulator links below no longer lead to the tools.)

I've used prc-tools 2.0. I'm running Linux.

You can get prc-tools from palmsource.com. Follow their directions for installation. You will need PilRC as well (version 2.7b or greater).

SDK - The current version of iRogue uses SDK 3.5 or higher (or, in the unlikely event that you want to compile for PalmOS 2.0, SDK 2; to compile for OS 2.0 you will also need to change which definition of CFLAGS is commented-out in the Makefile).

multigen - Since iRogue is large, it has "multiple code resources" and uses multigen. You might want to read about that in the prc-tools documentation.

emulator - The safest place to test software is in a Palm emulator. You will need a ROM image to use it.
