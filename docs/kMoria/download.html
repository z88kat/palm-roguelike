kMoria 0.16 (November 2026)

The current version. Download these files and install them with HotSync, or drag them onto an emulator such as CloudpilotEmu:

  • kMoria.prc - the game.
  • kMoriaDB.pdb - the game data: must be installed too.
  • kMoriaColorDB.pdb - optional: a colour scheme that works on both the white and the Invert (black) background (see color).
  • kMoria-manual.pdb - optional: the player's manual and the rules of Moria as a Palm DOC e-book.

See what's new, or read the manual online. You might also like to read about how to play. Found a bug? Please report it on GitHub.

System requirements

OS: Palm OS 3.5 or higher. On Palm OS 5 devices with a 5-way navigator (Tungsten C and others) the navigator walks.
Memory: about 320 K for the game and kMoriaDB, plus room for your saved game.

Original releases

The releases from 2000 to 2002 are still on SourceForge. The last was 0.15 (March 2002); see all kMoria releases. In those, the .zip file is the game and the .tar.gz file is the source code.
