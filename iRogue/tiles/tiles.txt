# iRogue tile set: the source of iRogueTileDB.prc
#
# tools/make-irogue-tiles.py turns this file into iRogueTileDB.prc (run by
# `make`). With Options > Preferences > Tiles checked, iRogue draws the map
# with these 10x9 pictures instead of letters.
#
# Each tile is a "tile" line followed by 9 rows of 10 pixels:
#
#   tile <symbol> <name> [rrggbb]
#
# <symbol> is the map character the tile replaces. Food is ':', walls are
# '-' and '|', and the dragon's flame is '~'. In the rows, every character
# is a colour from the table below. Two characters depend on the optional
# rrggbb at the end of the tile line: '#' is that colour and '=' is a darker
# shade of it. Monster colours match the built-in text colours.
#
#   copy <symbol> <other symbol>
#
# reuses another tile's picture.
#
# Symbols with no tile here (digits, other punctuation) show the letter
# itself in grey, taken from the 2002 starter set (iRogueTileDB-2002.prc).
#
# Use web-safe colours only (each of rr, gg, bb is 00, 33, 66, 99, CC or
# FF): those are the colours a 256-colour Palm can show exactly. Every tile
# has to read on both the white background and the black (Invert) one, so
# avoid large areas of white, black or yellow.

# "." is transparent: the background shows through.
