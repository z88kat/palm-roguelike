Download kMoria

Go to the Roguelikes for PalmOS project summary page on SourceForge. Download the "kMoria module" (it should be listed in the File Releases section). You will want the .zip file. The .tar.gz file is the source code.

Unzip it and follow the installation instructions. You might also like to read about how to play.
