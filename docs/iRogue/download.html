iRogue 1.2 (November 2026)

The current version. Download these files and install them with HotSync, or drag them onto an emulator such as CloudpilotEmu:

  • iRogue.prc - the game.
  • iRogueTileDB.prc - optional: the colour tile set, for Preferences > Tiles.
  • iRogue-manual.pdb - optional: the player's manual as a Palm DOC e-book.

See what's new, or read the manual online. You might also like to read about how to play. Found a bug? Please report it on GitHub.

System requirements

OS: Palm OS 3.5 or higher. On Palm OS 5 devices with a 5-way navigator (Tungsten C and others) you can play without the stylus.
Memory: about 130 K, plus about 10 K per save file, and 11 K for the tile set.

iRogue creates its own database, iRogueDB (saved games and high scores), the first time it runs.

Original releases

The releases from 2000 to 2002 are still on SourceForge. The last were 1.1.1 (development branch, May 2002, the first with tile support) and 1.0.0 (stable branch); see all iRogue releases. They also run on Palm OS 2: each zip has iRogue.prc for OS 3 and iRogueOS2.prc for OS 2. If your old version predates 0.42, delete it (or at least iRogueDB) before installing a newer one.
